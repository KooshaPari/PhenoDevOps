# Operations

## Docs Site

```bash
bun install
bun run docs:build
```

GitHub Pages builds with `GITHUB_PAGES=true`, which sets the VitePress base path
to `/PhenoDevOps/`.

## Local Validation

For docs-only changes:

```bash
bun run docs:build
```

For future Go runtime changes, use the project README checks once the runtime
surface is present in the tracked tree:

```bash
go test ./...
go build ./...
```

## Publishing Model

- VitePress emits static output under `docs/.vitepress/dist`.
- GitHub Pages deploys the static output from the Pages workflow.
- The generated `dist` directory is ignored and regenerated by CI.
