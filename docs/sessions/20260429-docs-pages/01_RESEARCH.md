# Research

## In-Repo Findings

- The canonical checkout has broad untracked scaffold churn.
- The isolated worktree started from tracked `main` and only contained README,
  governance docs, and placeholder workflows.

## Pattern Reused

- Followed the existing Phenotype VitePress docs pattern: docs under `docs/`,
  config under `docs/.vitepress/config.mts`, and Pages build with
  `GITHUB_PAGES=true`.
